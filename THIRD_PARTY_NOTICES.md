# Third-party notices

This homepage keeps the Jekyll build and adapts the visual structure and
interaction patterns from [Haoquan Zhang's homepage](https://github.com/HaoquanZhang/HaoquanZhang.github.io),
based on commit `188dc18`.

The target repository README explicitly welcomes reuse of its code and assets.
This site does not copy the target author's personal information, portrait,
research images, analytics ID, or verification metadata.

The project also retains the existing Minimal Mistakes/Jekyll theme files and
the local DeepSeek companion assets. Their source notice remains in
`images/deepseek/README.md`.
