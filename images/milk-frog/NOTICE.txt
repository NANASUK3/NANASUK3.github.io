The `*-24.webp` files are 24-frame animated WebP derivatives. They use
the source poses as keyframes and generated in-between frames, with a
42 ms frame duration (about 24 fps). The individual `idle-*`, `greet-*`,
and `laugh-*` files remain as static source/fallback references.

The homepage treats Naiwa / 奶蛙 as the community-created public character
described by the site owner. The source repository publishes its code and
project files under MIT and asks users to confirm the separate rights of the
character and reference artwork. Keep this notice with the derived frames.
