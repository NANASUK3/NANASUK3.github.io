The `laugh-60.webp` file is a 60-frame animated WebP derivative for the
homepage click interaction. It uses generated in-between frames with
alternating 16/17 ms frame durations (about 60 fps) and a total duration
of 1000 ms. The individual `idle-*`, `greet-*`, and `laugh-*` files remain
as static source/fallback references.

The homepage treats Naiwa / 奶蛙 as the community-created public character
described by the site owner. The source repository publishes its code and
project files under MIT and asks users to confirm the separate rights of the
character and reference artwork. Keep this notice with the derived frames.
